PAC-MAN
========

CONTROLS
--------
Arrow Keys   : Move / navigate menus
Enter        : Select option
Escape       : Pause the game

CHEATS (for testing/evaluation purposes)
-----------------------------------------
F1  : Invincibility
F2  : Level skip
F3  : Freeze ghosts
F4  : +1 life (7 lives max)
F5  : Increase Pac-Man's speed
F6  : Stop time

RULES
-----

- Collect all Pac-Gums and Super Pac-Gums to score points.
- Avoid the ghosts or lose a life.
- Complete each level before the timer runs out.
- Get the highest score possible!

CONFIGURATION
-------------
The game runs with default settings out of the box - just launch it,
no setup required.

if the game didn't have permission, run in TERMINAL:

chmod +x PacMan
